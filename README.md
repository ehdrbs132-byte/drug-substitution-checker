# 의약품 대체조제 조회 시스템 (Drug Substitution Checker)

복합제의 허가유형(신약·후발제네릭·자료제출의약품·위임제네릭)을 자동 분류하고, 두 약품 간 대체조제 가능 여부를 즉시 판별하는 웹 기반 프로토타입입니다.

## 관련 논문

최동균. "생성형 AI를 활용한 복합제 대체조제 정보장벽 해소 및 허가유형 판별도구 개발" 제21회 경기도약사회 학술대회, 2026.

## 라이브 데모

[https://cerulean-creponne-8d1759.netlify.app/](https://cerulean-creponne-8d1759.netlify.app/)

## 분류 로직 요약

5단계 의사결정 트리를 통해 의약품을 분류합니다.

1. **Step 1** — 품목기준코드 ∈ 대조약목록(File C) → **신약**
2. **Step 2** — 품목기준코드 ∈ 생동성인정품목(File A) → **후발제네릭**
3. **Step 3** — 한글명 접두사(Prefix) ∈ File A → **후발제네릭**
4. **Step 4a** — 제네릭묶음정보(File B) 자사열 발견 → **자료제출의약품**
5. **Step 4b/4c** — File B 위탁열 발견 시, 자사코드의 File A 존재 여부에 따라 → **후발제네릭** 또는 **위임제네릭**
6. 상기 어디에도 해당하지 않으면 → **분류불가**

## 사용한 데이터

식품의약품안전처(의약품안전나라 / 공공데이터포털)에서 제공하는 4개 공개 데이터베이스를 사용합니다.

| 파일 | 출처 | 설명 |
|------|------|------|
| `data_a.json` | 생동성인정품목 | 생물학적동등성이 인정된 품목 목록 |
| `data_b_jasa.json` / `data_b_witak.json` | 제네릭묶음정보 | 자사·위탁 제조 관계 데이터 |
| `data_c.json` | 대조약목록 | 신약·개량신약이 등재된 대조약 목록 |
| `data_d.json` | 의약품제품허가상세정보 | 약품 검색용 전체 허가 데이터 |

데이터 조회일: 2026년 4월 기준

## 실행 방법

서버가 필요 없는 클라이언트 전용 HTML 앱입니다.

1. 이 리포지토리를 다운로드합니다 (Code → Download ZIP).
2. `index.html`을 브라우저에서 열면 바로 실행됩니다.
